## 2. 检查方法

只扫描已跟踪内容（`git grep` 默认跳过未跟踪文件），另用 `git log -S` 回溯历史提交，避免“当前文件干净但历史里有密钥”。

```powershell
git grep -n -I -E 'sk-[A-Za-z0-9]{6,}|Bearer [A-Za-z0-9]|Authorization' -- .
git grep -n -I -E 'API_KEY\s*=\s*[^ \r\n]' -- .
git grep -n -I -E '[0-9a-f]{16,}\.[A-Za-z0-9]{8,}' -- .      # 智谱密钥 aaaa.bbbb 形态
git grep -n -I -E '1[3-9][0-9]{9}' -- .                     # 手机号
git grep -n -I -E '[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}' -- .
git grep -n -I -E '[0-9]{17}[0-9Xx]' -- .                   # 身份证
git grep -n -I -E '(1024|0824)[0-9]{5}' -- .                # 学号
git grep -n -I -E '[A-Za-z]:\\\\' -- .                      # Windows 绝对路径
git grep -n -I -E '\b(10|192\.168|172\.(1[6-9]|2[0-9]|3[01]))\.[0-9]{1,3}\.|Mayday|C:\\\\Users' -- .
git log --all --oneline -- .env
git log --all --oneline -S "sk-"
git log --format="%an <%ae>" | Sort-Object -Unique
```

截图另做两件事：字节级检查是否存在 `Exif` 段（判断有无拍摄设备与定位信息），并逐张目视核对画面中是否出现账号、手机号、余额等信息。
